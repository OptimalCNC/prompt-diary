# Project Synthesis Tools

Project Synthesis tools are MCP tools used by project-level synthesis agents while turning
evidence cards into work items.

Shared workspace, result, and error rules are defined in [MCP Tools](./index.md). The Project
Synthesis phase contract is defined in [Project Synthesis](../project-synthesis.md).

No project-synthesis MCP tools are defined yet. Add tool contracts here when this phase needs
agent-facing reads, writes, validation, or canonical artifact commits.
