# Daily Report Synthesis Tools

Daily Report Synthesis tools are MCP tools used by daily synthesis agents while turning work items
into `daily-report.json` and rendered report views.

Shared workspace, result, and error rules are defined in [MCP Tools](./index.md). The Daily Report
Synthesis phase contract is defined in [Daily Report Synthesis](../daily-synthesis.md).

No daily-synthesis MCP tools are defined yet. Add tool contracts here when this phase needs
agent-facing reads, writes, validation, or canonical artifact commits.
